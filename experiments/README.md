Pasta de experimentos - cada subpasta corresponde a um tipo de ataque/experimento.
Estrutura por ataque:
  runs/     - subpastas por execução com metadata e logs
  raw/      - arquivos brutos (pjsua logs, sipp output)
  pcaps/    - tcpdump/pcap por execução
  logs/     - logs processados do Asterisk e monitoramento
  metrics/  - CSVs com métricas extraídas
  plots/    - figuras geradas
  scripts/  - wrappers locais para executar o ataque
  params/   - wordlists, XML do SIPp, etc.
